## Contrato

- O ID de cenário é permanente; não reutilizar IDs removidos.
- `planejado` significa que o cenário está especificado, mas o teste ainda não foi implementado.

- O caminho da spec é concreto e deve corresponder à suíte indicada.
- Mudança de comportamento atualiza esta matriz, a feature e o arquivo de teste no mesmo PR.
