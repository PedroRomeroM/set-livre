# Runbook — incidente de segurança

1. declarar e nomear owner;
2. conter acesso/secret;
3. preservar logs/evidência;
4. rotacionar chaves;
5. avaliar dados e usuários;
6. bloquear actions afetadas;
7. corrigir e validar;
8. considerar comunicação legal/LGPD;
9. restore se integridade comprometida;
10. postmortem e novos testes.

Não divulgar PII em canal de incidente desnecessário.
